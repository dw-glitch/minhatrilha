# Minha Trilha — Qualidade + Tecnologia

Site estático e responsivo que recria o plano de formação profissional com pós-graduação em primeiro lugar.

## Como abrir

1. Descompacte o arquivo ZIP.
2. Abra `index.html` dando dois cliques.
3. O site funciona sem servidor, sem instalação e sem conta.
4. Uma conexão com a internet só é necessária para **abrir os links de cursos e instituições**.

## Conteúdo

- Cronograma profissional 2026–2029 (com parcelas de cursos que podem ir até 2030).
- Pós-graduação prioritária (PUC Minas), ENAP e cursos gratuitos Microsoft Learn.
- Cursos de Auditor Interno e Lean Six Sigma Green Belt.
- Agenda de 5h30 de estudo por semana, conciliando trabalho, academia e descanso.
- Simulador de teto mensal (R$ 200 a R$ 300), com alerta se a mensalidade de referência da pós superar seu teto.
- Checklist de 9 etapas salvo neste navegador (`localStorage`).
- Botão para exportar os estudos semanais em `.ics` para importar no Outlook ou Google Calendar.
- Opção de imprimir/salvar em PDF pelo navegador.

## Arquivos

- `index.html` — conteúdo e estrutura.
- `styles.css` — visual e responsividade.
- `script.js` — orçamento, checklist, filtros, menu e calendário.
- `favicon.svg` — ícone do site.

## Importante

Valores, condições e datas citados são **referências do planejamento de outubro de 2026**, não contratos, inscrições ou vagas confirmadas. Confira as ofertas atualizadas e os pré-requisitos diretamente com cada instituição. A taxa do exame Microsoft PL-300 não está incluída nos totais.

O checklist funciona localmente e suas marcações não acompanham o usuário entre navegadores/dispositivos. Nenhuma informação é enviada a um servidor por este site.

## Publicação opcional

Para colocar o site no ar, envie os arquivos da pasta para qualquer hospedagem estática (Netlify, Cloudflare Pages, GitHub Pages, etc.). O `index.html` deve ficar na raiz do site. Nenhuma etapa de compilação é necessária.
